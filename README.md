## How to run

1. Clone the repository: `git clone https://github.com/KarinaArakelyan3/Midterm-Labs.git`
2. Open the solution for the lab you want:
   - [Lab_1/Lab_1.sln](./Lab_1/Lab_1.sln)
   - [Lab_2/Lab_2.sln](./Lab_2/Lab_2.sln)
   - [Lab_3/Lab_3.sln](./Lab_3/Lab_3.sln)
   - [Lab_4/Lab_4.sln](./Lab_4/Lab_4.sln)
3. Press Start (F5) in Visual Studio.

Labs 1, 2, and 4 print a result as soon as they start. Lab 3 waits for input in the console.
